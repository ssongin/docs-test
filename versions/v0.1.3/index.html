Description
Consumers

Keep project roots clean

VitePress and its lockfile live under docs/, so Java, Go, and other projects do not need a root package.json.

Preview every active PR

Same-repository pull requests publish to their own /pr-N/ URL and receive a preview comment.

Reuse the publishing workflow

One workflow builds the site, updates GitHub Pages, and removes closed PR previews.

gh-docs is a reusable documentation site and GitHub Actions workflow for publishing static documentation to GitHub Pages. The docs project is isolated in docs/, making it suitable for Java, Go, and other non-Node repositories.
