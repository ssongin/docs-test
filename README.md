# gh-docs

Reusable static documentation and GitHub Pages deployment for any repository. The VitePress project lives in `docs/`, so it does not add Node.js files to the application root.

Start the docs site locally:

```bash
npm ci --prefix docs
npm --prefix docs run docs:dev
```

See the [documentation](docs/index.md) for setup instructions, Markdown examples, and details on publishing and pull request previews.
